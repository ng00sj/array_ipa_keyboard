# 行列暨國際音標鍵盤（array-ipa-keyboard）
算是做給我個人用的 Android 輸入法，行列輸入法是我平常在用的輸入法，因為個人愛好語音學，因此做了一個 Latin 字母鍵盤附上 IPA 字符和一些雜七雜八的符號。

## 安裝方式
這是一個 Android Studio 的專案，我目前沒有放上 APK 連結（也許以後做受眾更多的話會放），因此足下可以自行下載，打包成 APK 安裝使用。

## 使用方式
有三個鍵盤介面，按#符號可以切換：
* 行列鍵盤
  * 使用方法見行列官方的教學，基本相同。
* Latin 字母鍵盤
  * 含 IPA 等特殊符號，有空我會統整我使用的字碼區間。
  * 長按 Enter 切換到大寫，再長按換回來。
  * 不管大寫小寫時，按 Latin 字母，上排數字鍵會成為選單，有與該字母相關的 IPA 字符。
  * 長按數字鍵 0~9 會有其它 IPA 符號，例如附加字元（上、中、下）、聲調符號等。
  * 長按!、@等符號（當然得先按 Enter 切換到大寫），會有非 IPA 的擴充字符。
* 標點符號
  * 這部分內容不豐富，因為需求不急迫，僅有中等常見的符號，有打算再擴充。

其餘按鈕：
* ◎：可以換顏色。
* ✔：提交。
* ✘：取消選取特殊符號。
